# Диаграммы ВКР и проектной документации

Исходные тексты всех диаграмм работы. На каждой диаграмме есть блок «Обозначения». IDEF0 и IDEF3 описывают процесс лаборатории «как есть» — без информационной системы; остальные диаграммы — проектируемую систему.

Сборка изображений (в репозиторий изображения не кладутся):

```bash
java -jar plantuml.jar -tpng -charset UTF-8 *.puml          # PlantUML 1.2025+
python idef0.py 02_idef0_context.json 02_idef0_context.png  # IDEF0, matplotlib
python idef0.py 03_idef0_a0.json 03_idef0_a0.png
python 04_dfd.py                                            # DFD (Гейн–Сарсон), Graphviz
python 10_architecture.py                                   # архитектура, Graphviz
python docs/diagrams/er_from_models.py                      # из корня репозитория: 12a–12d по app/models.py
```
