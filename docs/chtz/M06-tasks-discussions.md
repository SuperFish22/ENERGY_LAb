# ЧТЗ М-06. Задачи и обсуждения по отделам (личный кабинет)

**Основание:** ТЗ, ЧТЗ-4 (CAB-12, CAB-14 – CAB-16), пожелание заказчика: «у каждого свой личный кабинет; через бота смотреть свои задачи и накидывать вопросы на обсуждение в соответствии с отделом».
**Код:** `app/routers/cabinet.py` (разделы «задачи», «обсуждения», «профиль»), шаблоны `cabinet/dashboard.html`, `tasks.html`, `discussions.html`, `discussion.html`, `profile.html`.

## 1. Назначение

Дать каждому участнику один экран, где видно, что ему делать к ближайшему запуску, и место, где отдел обсуждает вопросы, — в кабинете и в мессенджере.

## 2. Функциональные требования

### Обзор («Центр управления»)

| ID | Требование |
|---|---|
| М06-01 | После входа — ближайший запуск с обратным отсчётом, мои открытые задачи по сроку, проекты, где я эксперт и тур открыт, мои проекты, открытые обсуждения моего отдела |

### Задачи

| ID | Требование |
|---|---|
| М06-02 | Задача: название, описание, проект (необязательно), отдел, исполнитель, срок, статус «К выполнению / В работе / Готово» |
| М06-03 | Ставить задачу может любой участник; исполнитель получает уведомление в выбранный мессенджер |
| М06-04 | Менять статус может исполнитель, автор задачи или руководитель |
| М06-05 | Список «Мои» (назначенные мне и поставленные мной) и «Все» (только руководителю), сортировка по статусу и сроку, просроченные подсвечены |

### Обсуждения

| ID | Требование |
|---|---|
| М06-06 | Обсуждение принадлежит отделу, может ссылаться на проект; поле «Источник» — кабинет, Telegram или VK |
| М06-07 | Создать обсуждение и ответить можно из кабинета и из бота (М-08); эксперты отдела получают уведомление о новом вопросе, автор — об ответе |
| М06-08 | Список по умолчанию фильтруется по моему отделу; переключатель отделов |
| М06-09 | Закрыть обсуждение может автор или руководитель; в закрытое нельзя писать |

### Профиль

| ID | Требование |
|---|---|
| М06-10 | ФИО, телефон (для SOS-рассылки руководителям), канал уведомлений: Telegram, ВКонтакте или «Не присылать» |
| М06-11 | «Привязать мессенджер»: одноразовый 6-значный код на 10 минут; отправить боту `/link КОД` |
| М06-12 | Отвязать мессенджер можно кнопкой в профиле или командой бота `/unlink` |

## 3. Данные

`tasks`, `discussions`, `messages`, `link_codes`, `notifications`; поля `users.telegram_id`, `vk_id`, `notify_channel`, `phone`.
