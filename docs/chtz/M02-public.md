# ЧТЗ М-02. Публичный сайт: афиша, карточка, анкета гостя, доска вопросов

**Основание:** ТЗ, ЧТЗ-2 (требования LAB-01 – LAB-12).
**Код:** `app/routers/public.py`, шаблоны `app/templates/public/*`.

## 1. Назначение

Показать гостям ближайшие «запуски» Energy Lab, продать билет через Timepad, собрать оценку после мероприятия и принять вопросы на доску.

## 2. Границы

Входит: главная с обратным отсчётом, афиша, карточка мероприятия, анкета гостя, доска вопросов, политика конфиденциальности.
Не входит: оплата (её проводит Timepad, он же выдаёт кассовый чек по 54-ФЗ), личный кабинет гостя.

## 3. Функциональные требования

| ID | Требование | Реализация |
|---|---|---|
| М02-01 | Главная: «Т−N дней» до ближайшего мероприятия в статусе «Продажа билетов», кнопка «Купить билет», три следующих запуска, итоги прошлых | `GET /` |
| М02-02 | Афиша: будущие мероприятия в продаже и архив проведённых; возрастная маркировка по 436-ФЗ рядом с названием | `GET /afisha` |
| М02-03 | Карточка `/e/{код}`: описание, дата, время, площадка, цена, возраст, станции без внутренних данных (стоимость, ответственные скрыты), виджет Timepad | `GET /e/{code}` |
| М02-04 | Если виджет Timepad не загрузился за 5 с — показать прямую ссылку на страницу Timepad | `event.html` |
| М02-05 | Условия возврата по ст. 52.1 Основ законодательства о культуре: полная сумма — более 10 дней, 50 % — 5–10 дней, 30 % — 3–5 дней, менее 3 дней — не возвращается, кроме уважительных причин | `event.html` |
| М02-06 | Разметка Schema.org `Event` для поисковиков | `event.html` |
| М02-07 | Мероприятия в статусах до «Продажа билетов» в публичной части не видны (404) | `public.event_page` |
| М02-08 | Анкета гостя доступна в день мероприятия и 7 дней после: общая оценка 1–5, NPS 0–10, оценка станций, комментарий, необязательный e-mail | `GET/POST /e/{code}/feedback` |
| М02-09 | Повторная анкета с того же браузера отклоняется (cookie + хеш IP и User-Agent); e-mail сверяется с купленными билетами, совпадение отмечается «подтверждённый гость» | там же |

| М02-11 | В подвале — отметка «Instagram принадлежит Meta, признанной экстремистской и запрещённой в РФ», ссылки на VK и Telegram | `partials/public_foot.html` |
| М02-12 | Политика обработки ПДн на `/privacy` | `GET /privacy` |

## 4. Данные

Чтение: `events`, `stations`, `event_results`, `venues`. Запись: `feedback`, `feedback_stations`, `questions`.

## 5. Правила

* Анкета хранит не IP, а `client_hash = sha256(соль + IP + UA)`.
* Вопрос с доски не длиннее 1000 символов; HTML экранируется шаблонизатором.
* Реклама в Instagram с 01.09.2025 запрещена — ссылок на него как на рекламный канал нет.

## 6. Нефункциональные

Страница отдаётся сервером целиком (без SPA), весит не больше 150 КБ без шрифтов, читаема при ширине 360 px, контраст текста не ниже 4,5:1.
