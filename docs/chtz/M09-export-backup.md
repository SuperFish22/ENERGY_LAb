# ЧТЗ М-09. Выгрузка в шаблоны Google Диска, дублирование, резервные копии

**Основание:** ТЗ (общее), требования к системе SYS-14, SYS-15; пожелание заказчика: «дублирование информации и возможность выгрузки в разработанные шаблоны на Google Диск».
**Код:** `app/export.py`, методы `/cabinet/projects/{id}/export.{json|csv}`, `/cabinet/registry.csv`, `/api/bot/export/*`; `deploy/backup.sh`, `deploy/restore.sh`; сценарий `n8n/workflows/google-drive-export.json`.

## 1. Назначение

Чтобы команда могла работать с привычными документами ENERGY на Google Диске (паспорт проекта, заключение, отчёт), а данные не терялись при сбое сервера.

## 2. Ключевое ограничение

Google — иностранный сервис. Поэтому система **не** отправляет туда персональные данные: в выгрузку не попадают гости, e-mail, телефоны, ответы анкет. Уходят только данные о мероприятии, станциях и агрегированные цифры. Отправку выполняет n8n на внешнем сервере; сам сервер в РФ к Google не обращается (кроме зашифрованной резервной копии, см. п. 5).

## 3. Шаблоны документов

Заказчик готовит шаблоны в Google Docs с метками вида `{{TITLE}}`. n8n копирует шаблон в папку проекта и заменяет метки.

| Метка | Значение |
|---|---|
| `{{CODE}}`, `{{TITLE}}`, `{{FORMAT}}`, `{{STATUS}}`, `{{STAGE}}` | код, название, формат, статус, стадия запуска |
| `{{DATE}}`, `{{TIME}}`, `{{VENUE}}`, `{{AGE}}`, `{{CAPACITY}}` | дата, время, площадка, возраст, мест |
| `{{PRICE}}`, `{{BUDGET_PLAN}}`, `{{STATIONS_COUNT}}`, `{{STATIONS_COST}}` | цена билета, плановый бюджет, станции |
| `{{AUDIENCE}}`, `{{DESCRIPTION}}`, `{{AUTHOR}}` | аудитория, концепция, автор |
| `{{SCORE}}`, `{{KENDALL_W}}`, `{{RISK}}`, `{{RECOMMENDATION}}` | итоги экспертизы |
| `{{ATTENDANCE}}`, `{{ATTENDANCE_RANGE}}`, `{{TICKETS_FORECAST}}`, `{{REVENUE_FORECAST}}`, `{{BUDGET_FORECAST}}`, `{{RATING_FORECAST}}` | прогноз |
| `{{DECISION}}`, `{{DECISION_COMMENT}}` | последнее решение руководителей |
| `{{GUESTS_FACT}}`, `{{TICKETS_FACT}}`, `{{REVENUE_FACT}}`, `{{COST_FACT}}`, `{{RATING_FACT}}` | факт |
| `{{URL}}` | ссылка на проект в кабинете |

Таблица станций отдаётся отдельным массивом `stations` (№, название, мин, ₽, ответственный).

| ID | Требование | Статус |

## 5. Почему резервную копию можно хранить на Google Диске

Копия зашифрована GPG до отправки, ключ хранится только у руководителей. Без ключа файл — набор байтов; оригинал БД остаётся в РФ. Если заказчик против — в `backup.sh` достаточно не настраивать rclone, копии останутся только на сервере.
