# ЧТЗ М-05. Прогноз по аналогам, рекомендация, компетентность экспертов

**Основание:** ТЗ, ЧТЗ-3 (EXP-12 – EXP-16), раздел 2.3 ВКР (метод Г).
**Код:** `app/expertise/forecast.py`, `competence.py`, `service.py`; шаблоны вкладки «Прогноз и решение» и `cabinet/conclusion.html`.

## 1. Назначение

По прошлым мероприятиям Energy Lab предсказать явку, продажи, выручку, бюджет и оценку гостей нового проекта, дать руководителям понятную рекомендацию и со временем точнее взвешивать мнения экспертов.

## 2. Метод Г — ближайшие аналоги (kNN)

Признаки и веса: формат 0,35; цена 0,20; вместимость 0,15; сезон 0,10; экспертная оценка 0,20.

* Числовые признаки нормируются min-max по базе аналогов.
* Формат: 0 — тот же код, 0,5 — та же группа классификатора, 1 — другая группа.
* Сезон — по месяцу на окружности (декабрь рядом с январём).
* Расстояние d = Σ wᵢ·|Δᵢ|; берутся k = 3 ближайших мероприятия в статусе «Проанализирован».
* Прогноз — среднее с весами 1/d (IDW); при d = 0 берётся аналог как есть.
* Явка переносится через долю заполнения зала аналога на вместимость нового проекта; продажи и выручка — через явку и цену.
* Бюджет = Σ стоимость станций × (1 + средний перерасход аналогов).
* Диапазон явки — минимум и максимум по аналогам, пересчитанные так же.

Если аналогов меньше трёх — прогноз строится по имеющимся с пометкой «мало данных»; если их нет — показываются только экспертные показатели.

## 3. Рекомендация

Правила по порядку: S < 3 → «Отклонить»; красная станция, или W < 0,5 после двух туров, или S < 3,5 → «Доработать»; иначе «Утвердить». Если прогноз бюджета больше прогноза выручки — добавляется предупреждение «бюджет выше выручки». Причины выводятся списком. Решение принимает руководитель, рекомендация его не связывает.

## 4. Компетентность

После «Разбора полёта» для каждого эксперта: точность aₑ = 1 − |Sₑ − r| / 4, где r — средняя оценка гостей; cₙₒᵥ = (1 − η)·c + η·aₑ, η = 0,2; результат ограничен [0,5; 1,0]. Новый эксперт начинает с 0,7. Каждое изменение пишется в `competence_history` с мероприятием.
