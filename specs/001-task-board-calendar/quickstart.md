# Быстрая проверка: доска задач и календарь задач

## Локально

```powershell
.\venv\Scripts\Activate.ps1
alembic upgrade head          # применит 0005
python -m app.seed --demo     # демо-задачи разложатся по всем четырём колонкам
uvicorn app.main:app --reload
```

1. Войдите как `script@energy.local` / `demo12345` → «Задачи». Откроется доска. Перетащите карточку «К выполнению → В работе», обновите страницу: карточка на месте.
2. Перетащите её в «Выполнено». Задачу поставил другой человек, поэтому она уйдёт в «На проверке».
3. В другом окне войдите как `admin@energy.local` / `admin12345`. «Задачи» → «Все», найдите карточку в «На проверке», верните «В работу» без комментария. Появится сообщение «Напишите, что исправить».
4. «Задачи» → «Календарь»: задачи стоят в днях срока, старт «Ночь в музее» отмечен. Клик по пустому дню откроет форму с подставленным сроком.
5. «Обзор»: полоса «Эта неделя» и счётчики колонок.
6. Сузьте окно до 360 px: колонки листаются по горизонтали, у карточек вместо перетаскивания список статусов.
7. «Профиль» → «Календарь» → «Включить», подтвердите предупреждение. Откройте ссылку `/cal/….ics` в браузере: скачается файл календаря.

## Подключение к Google и Яндексу

Google и Яндекс забирают подписку со своих серверов, поэтому локальный `127.0.0.1` они не увидят. Проверяйте на сервере `lab.energy-academia.duckdns.org`:

- Google: «Профиль» → «Подключить к Google Календарю» → «Добавить». Задачи появятся в течение нескольких часов, частоту обновления определяет Google.
- Яндекс: «Подключить к Яндекс Календарю» → ссылка скопирована → в Яндекс Календаре добавить подписку по ссылке.
- «Выпустить новую ссылку»: старая ссылка начинает отвечать 404, календарь перестаёт обновляться.
